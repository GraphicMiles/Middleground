# Middleground

A first-person wetland exploration game built with Three.js. Terrain is generated from a fixed seed, with chunks loaded as the player moves.

## Play

Open `index.html` in a browser with WebGL support. The file includes the runtime, game code, and textures.

To serve it locally, run this from the repository root:

```sh
python -m http.server 8080
```

Then open `http://localhost:8080` and select **Tap to explore**.

### Controls

| Desktop | Action |
| --- | --- |
| W, A, S, D | Move |
| Mouse | Look |
| Shift | Sprint |
| Space | Jump |

Click the canvas to lock the mouse, or drag to look. On touch screens, use the left side to move and the right side to look. Push the movement stick to its edge to sprint.

The on-screen buttons control jumping, sprinting, time of day, graphics quality, and look sensitivity. Graphics, sensitivity, and time settings are saved locally. Audio starts after entering the game.

## Game systems

- Seeded terrain with streamed chunks and collision handling.
- A 36-minute day and night cycle, with a time-skip button.
- Water depth shading, wind-driven waves, and wading ripples.
- Sand, clay, and wet-ground materials, with reeds and floating plants.
- Antelope herds, birds, and procedural nature audio.
- AUTO, LOW, and HIGH graphics settings.

## Build

Python 3 builds the game from `src/base.html`, the source modules, and the assets:

```sh
python scripts/build.py
```

The build writes `index.html`. Edit the source files, then rebuild. To include a JavaScript syntax check, install Node.js 20 or later and run:

```sh
npm run build
```

### Ground textures

The texture generator uses Pillow:

```sh
python -m pip install Pillow
python scripts/bake_ground.py
python scripts/build.py
```

## Tests

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

Tests cover terrain heights, starting chunk layouts, collisions, controls, saved settings, water interaction, WebGL1, and chunk regeneration. They also check loading with network access disabled.

The test runner uses Chromium with software WebGL. Measure frame rates on physical devices when assessing performance.

## Layout

```text
index.html                  Playable build
src/                        Game modules and original build input
assets/                     Three.js runtime and ground textures
scripts/                    Build and texture generation
tests/                      Browser tests and regression data
docs/                       Ground material references
```

See [Ground materials](docs/ground-materials.md) for the palette and surface design.
